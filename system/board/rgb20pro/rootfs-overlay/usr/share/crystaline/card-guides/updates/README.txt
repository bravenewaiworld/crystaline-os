Crystaline OS writes this file. Don't edit it: your changes are undone the next time the RGB20 Pro starts.

Crystaline OS update files (ending in .update) go in this folder.

1. Download the .update file of a release from
   https://github.com/bravenewaiworld/crystaline-os/releases
2. Copy it into this folder, as it is (don't unpack it).
3. Hold SELECT and START while turning the RGB20 Pro on, until the recovery
   menu appears. Choose "Install an update from the SD card", then the file.

The version you were running stays on the card, so you can go back to it:
choose "Start the previous version" in the same menu.

Once installed, the file can be deleted.
