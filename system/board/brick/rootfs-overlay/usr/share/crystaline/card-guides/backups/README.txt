Crystaline OS writes this file. Don't edit it: your changes are undone the next time the Brick starts.

This folder holds the copy of TrimUI's system that was made when Crystaline OS
was installed to the Brick's internal storage. It is your way back to TrimUI's
system: don't delete it, and keep this card. A copy on a PC is a good idea too
(copy the whole backups folder to the PC; to use it, copy it back into this
card's backups folder).

To put TrimUI's system back:
1. Charge the Brick to at least half, or keep it charging.
2. With this card in, on the Brick: Settings > Internal storage > Restore
   internal storage, and choose the backup. Then restart the Brick: it starts
   from this card to do the restore.
3. When it asks, choose Restore. This writes the copy back over Crystaline OS
   on the internal storage.
4. When it is done, turn the Brick off, take this card out, and turn it on.

A folder whose name ends in .partial is a backup that didn't finish; it can't
be restored, and the next backup deletes it.
