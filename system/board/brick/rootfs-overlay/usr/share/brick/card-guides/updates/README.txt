Crystaline OS writes this file. Don't edit it: your changes are undone the next time the Brick starts.

Crystaline OS update files (ending in .update) go in this folder.

1. Download the .update file of a release from
   https://github.com/bravenewaiworld/crystaline-os/releases
2. Copy it into this folder, as it is (don't unpack it).
3. On the Brick: Settings > Updates > Install update, and choose the file.
   Then restart the Brick.

The version you were running stays on the Brick, so you can go back to it:
Settings > Updates > Start previous version. If the new version doesn't start,
hold MENU while turning the Brick on, until the recovery menu appears: it can
start the previous version, or install an update file from this folder.

Once installed, the file can be deleted.
